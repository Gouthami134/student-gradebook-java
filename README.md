# Student Gradebook (Java)

An original, small command-line learning project. It lets a user enter students and subject marks, list the entries, search by name, and view a computed average and letter grade. Records live in memory and are cleared when the program exits.

## Requirements

- Java Development Kit (JDK) 17 or later
- A terminal

## Run

From this folder:

```sh
javac GradebookApp.java
java GradebookApp
```

## Concepts demonstrated

Java classes, lists, streams, loops, switch expressions, formatted output, and basic input validation.

## Scope and next steps

This is a learning exercise, not a student information system. It stores no data after exit and has no authentication. Possible extensions include CSV storage, editing a student's marks, and configurable grading bands.
